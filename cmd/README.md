# cmd

## Назначение каталога
- Точка входа приложения: `main.go` создаёт корневой контекст с отменой по сигналу (`SIGTERM`, `os.Interrupt`) и передаёт управление в слой композиции.
- Слой относится к композиции/bootstrapping и не содержит бизнес-логики.

## Правила зависимостей
- Импортирует только `internal/application`; не тянет доменные или инфраструктурные пакеты напрямую.
- Любые новые флаги/обработчики сигналов добавляются здесь, но создание зависимостей остаётся задачей `internal/application`.

## Конвенции и практики
- Контекст создаётся через `signal.NotifyContext`, отмена откладывается через `defer cancel`.
- Ошибки старта приложения логируются и приводят к `log.Fatalf`, завершая процесс.
- Вся настройка окружения (config/logger/db) выполняется ниже по стеку, чтобы точка входа оставалась тонкой.

## Ключевые артефакты
- `main.go` — создание контекста и запуск `application.Run`.

## Нарушения/риски
- Дополнительные сигналы (`SIGHUP`, `SIGQUIT`) не обрабатываются; если их нужно ловить — добавить в список.
- Контекст не передаётся в HTTP-сервер/джобы напрямую; управлением жизненным циклом занимается `application`.
