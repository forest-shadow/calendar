# internal/transport/http

## Назначение каталога
- Обертка над `net/http.Server` с ручным созданием listener, запуском и остановкой.
- Используется приложением для старта REST API.

## Правила зависимостей
- Принимает готовый `http.Handler` (роутер) и конфиг; не создает сервисы или маршруты самостоятельно.
- Может логировать события старта/остановки, но не должен зависеть от доменных пакетов.

## Конвенции и практики
- Listener создается заранее через `net.Listen` для явной обработки ошибок портов.
- Запуск сервера выполняется в отдельной горутине, ошибки старта, отличные от `http.ErrServerClosed`, считаются фатальными.
- Остановка производится через `Shutdown` с таймаутом `ServerShutdownTimeout`.

## Ключевые артефакты
- `server.go` — конструктор и методы `Start`/`Stop` для HTTP-сервера.

## Нарушения/риски
- Запуск сервера не принимает корневой контекст и не настраивает таймауты чтения/записи/простоя, что может привести к зависшим соединениям под нагрузкой.
- При ошибке `Serve` (кроме `ErrServerClosed`) вызывается `panic`, что ломает возможность контролируемого завершения приложения.
