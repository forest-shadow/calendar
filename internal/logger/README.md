# internal/logger

## Назначение каталога
- Обертка над zap для приложения и отдельный логгер для нотификатора с ротацией через lumberjack.
- Единая точка настройки уровня логирования и формата (JSON).

## Правила зависимостей
- Использует только конфиг и стандартную библиотеку; может импортироваться из любых слоев.
- Новые компоненты должны получать `logger.Logger` через конструкторы, а не создавать свои экземпляры.

## Конвенции и практики
- Уровень логирования определяется окружением: `production` → Info, иначе Debug.
- Логи пишутся в stdout; нотификатор дополнительно дублирует вывод в файл из конфига.
- Логгер обогащается контекстными полями (`With`) для компонентов (`app`, `cleaner_job`, `notifier_job`).

## Ключевые артефакты
- `logger.go` — создание основного SugaredLogger.
- `event_notifier_logger.go` — конфигурация логгера с ротацией для фонового нотификатора.

## Нарушения/риски
- Логгеры не вызывают `Sync()` при остановке приложения, возможна потеря последних сообщений при резком завершении.
- Нет настройки уровней/энкодеров из конфига (кроме окружения), хотя это отмечалось в требованиях HW.
