# internal/config

## Назначение каталога
- Загрузка конфигурации приложения из YAML-файлов `env.*.yml` и переменных окружения с префиксом `APP_`.
- Описание структуры настроек HTTP, БД, джобов, Kafka и уровня окружения.

## Правила зависимостей
- Не зависит от других внутренних пакетов; импортируется остальными слоями для получения настроек.
- Новые компоненты добавляются через поля в `Config` и сопутствующие структуры.

## Конвенции и практики
- viper читает файл `env.<APP_ENV>.yml` из корня; при отсутствии файла ошибки только логируются, поэтому значения могут остаться нулевыми.
- Переменные окружения перекрывают значения из файла; точки в ключах заменяются на подчеркивания.
- Валидация значений (URI БД, интервалы джобов) не выполняется здесь и должна делаться на уровне потребителей.

## Ключевые артефакты
- `config.go` — структура `Config`, загрузка через viper.
- `env.example.yml`, `env.local.yml` (в корне) — примеры значений для локальной среды и контейнеров.

## Нарушения/риски
- Ошибка чтения конфига лишь печатается в stdout и игнорируется, что может скрыть отсутствие файлов.
- Нет валидации интервалов/портов/URI; некорректные строки попадут в рантайм и вызовут ошибки позже (например, в джобах при `time.ParseDuration`).
