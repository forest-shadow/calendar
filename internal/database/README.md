# internal/database

## Назначение каталога
- Инициализация подключения к Postgres через `pgx`/`database/sql` и экспонирование `DBConnection` для репозиториев.
- Отвечает за проверку соединения и предоставление функции закрытия.

## Правила зависимостей
- Импортирует только конфиг и логгер; другие пакеты используют готовый `*sql.DB` без знания деталей инициализации.
- Не добавлять бизнес-логику или SQL-запросы; они должны жить в доменных репозиториях.

## Конвенции и практики
- URI базы читается из `config.DB.URI` и парсится через `pgx.ParseURI`.
- Подключение создаётся один раз на старте приложения и закрывается в `application.shutdown`.
- Настройки пула/таймаутов пока не заданы; при необходимости нужно расширить конфиг и конструктор.

## Ключевые артефакты
- `db.go` — конструктор `NewDB`, типы `DB` и `DBConnection`.

## Нарушения/риски
- Отсутствуют параметры пула (max open/idle, таймауты), что может привести к исчерпанию соединений под нагрузкой.
- Нет миграции/инициализации расширений БД (например, `pgcrypto` для `gen_random_uuid()` в миграции), ошибки всплывут только на этапе запуска.
