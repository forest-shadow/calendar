# scripts

## Назначение каталога
- Вспомогательные файлы для инфраструктуры и разработки: Dockerfile миграций, hurl-запросы, установка pre-commit хуков.
- Поддерживает цели Makefile (`migration-create`, `migrate`, `run`, `test`).

## Правила зависимостей
- Скрипты предполагают наличие docker/docker-compose, `yq`, утилит из `tools/bin` (goose, air, golangci-lint).
- Изменения в миграционном Dockerfile должны быть синхронизированы с версиями goose и путями проекта.

## Конвенции и практики
- Hurl-запросы используют переменную `host` и соответствуют текущим ручкам (`events`, `healthcheck`).
- Pre-commit устанавливается через `setup-pre-commit.sh` и подключает линтер перед коммитами.
- Миграционный образ ожидает GOOSE_* переменные окружения, задаваемые в docker-compose.

## Ключевые артефакты
- `migration.Dockerfile` — сборка образа для запуска goose миграций.
- `requests/events.hurl`, `requests/healthcheck.hurl` — сценарии для ручного тестирования API.
- `setup-pre-commit.sh` — установка git hook.

## Нарушения/риски
- Зависимость от внешних инструментов (`yq`, docker, goose) не проверяется автоматически; запуск `make run` упадет без них.
- Hurl-сценарии не покрывают все ручки (нет update/delete), поэтому регрессия части API останется незамеченной.
