# test/mocks

## Назначение каталога
- Сгенерированные gomock моки для интерфейсов сервисов, используемых в юнит-тестах контроллеров и других компонентов.

## Правила зависимостей
- Не изменяются вручную; источник интерфейсов должен оставаться стабильным или требовать регенерации через `mockgen`.
- Используются только в тестах, не импортируются продукционным кодом.

## Конвенции и практики
- Комментарий в файле фиксирует источник генерации (`internal/application/domain_events.go`).
- При изменении интерфейса `eventService` нужно заново запустить `mockgen` для актуализации.

## Ключевые артефакты
- `events_service_mock.go` — мок интерфейса `eventService` для тестов контроллеров.

## Нарушения/риски
- Интерфейс-источник дублируется в разных пакетах; при несинхронных изменениях мок может не соответствовать фактическому контракту сервиса.
