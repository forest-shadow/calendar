# test/util

## Назначение каталога
- Хелперы для интеграционных тестов: поднятие Postgres в контейнере, применение миграций и управление жизненным циклом.

## Правила зависимостей
- Использует `testcontainers-go`, `goose` и конфиг/базу из `internal`; не зависит от HTTP или доменных сервисов.
- Должен оставаться изолированным, чтобы переиспользоваться в разных тестовых наборах.

## Конвенции и практики
- `NewTestDB` создает контейнер Postgres 16-alpine, возвращает подключение и функцию закрытия.
- `RunMigrations` запускает goose для указанной директории миграций.
- Используются `require`/`assert` из testify для немедленного падения при ошибке инфраструктуры.

## Ключевые артефакты
- `db.go` — создание/закрытие тестовой базы и запуск миграций.
- `db_test.go` — проверки connectivity и корректности схемы/сидов после миграций.

## Нарушения/риски
- Тестовые утилиты требуют Docker и сеть; при недоступности среды тесты упадут без graceful skip.
- Не включают создание расширений (`pgcrypto`) перед миграциями, что может ломать сиды с `gen_random_uuid()`.
